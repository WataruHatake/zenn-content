# はじめに

今回、AWS Certified Cloud Practitioner（CLF-C02）を取得しました。

資格取得を始めたきっかけは、会社の研修です。

新卒で入社したあと、4月にファーム全体の研修が終了し、6月には会社単体の研修も終了しました。その後、所属組織での研修が始まり、その中で **AWS・基本情報技術者・Azure・GCPのいずれかの資格を研修期間中に取得する** 必要がありました。

もともとAWSやクラウド領域には興味があり、将来的にはAWSやGCPの資格を複数取得していきたいと考えていました。

せっかく資格取得が必要なのであれば、まずはAWSから本格的に勉強を始めてみようと思い、最初の資格としてCloud Practitionerを選びました。

## なぜChatGPTで勉強したのか

会社からUdemyのアカウントが付与されており、講座自体は自由に利用できる環境でした。

ただ、個人的には動画を見ながら勉強する方法があまり合いませんでした。

分かっている部分でも動画の進行に合わせる必要があり、逆に理解できなかった部分を振り返るときには巻き戻して該当箇所を探す必要があります。

書籍での学習も試しましたが、分からない部分が出たときにその場で質問できないことにもどかしさを感じました。

そこで目をつけたのがChatGPTです。

ChatGPTであれば、

- 自分のペースで学習を進められる
- 分からないことをその場で質問できる
- 理解できなければ別の説明方法を求められる
- 問題をその場で作ってもらえる
- 間違えた理由まで掘り下げて確認できる

という使い方ができます。

また、AWSのようなクラウドサービスはアップデートが多いため、必要に応じて公式ドキュメントや最新情報を確認しながら学習できる点も、生成AIと相性が良いと感じました。

もちろん、AWSサービスの最新仕様と資格試験の出題内容が常に一致するとは限りません。

ただ、私のゴールは資格を取得することだけではなく、その先の業務でも使えるAWSの知識を身につけることです。

そのため今回は、ChatGPTを学習の中心に置きつつ、必要に応じてAWS公式情報を確認する形で勉強を進めました。

# 14日間の学習方法

7月28日に学習を開始すると同時に、試験日も設定しました。

当初は8月8日に受験する予定でした。

学習を始める上で最初に行ったことは、ChatGPTに学習スケジュールを作成してもらうことです。

平日は1〜2時間、土曜日は4時間、日曜日は1時間程度という大まかな学習時間を設定し、その中で試験日までに必要な学習内容を整理しました。

ただし、最初に作成したスケジュールをそのまま進めるのではなく、自分の理解度や進捗状況に合わせて、その都度ChatGPTに修正してもらいました。

## 前半：主要なAWSサービスの理解

学習開始直後は、AWSの主要サービスを中心に全体像を理解することから始めました。

最初から細かな仕様を暗記するのではなく、

- そのサービスは何を解決するものなのか
- どのような場面で利用されるのか
- 似たサービスとの違いは何か

を理解することを意識しました。

例えばAmazon EC2であれば、単に「仮想サーバー」と覚えるだけではなく、

「オンプレミスでサーバーを用意する場合と何が違うのか」

「AWS Lambdaとはどう使い分けるのか」

といったところまで質問しました。

また、1つの分野の学習が終わるたびにChatGPTに小テストを作成してもらい、理解度を確認しました。

説明を読むだけではなく、問題を解きながら知識を定着させる形です。

## 中盤：ChatGPT製の問題で9割を超えたが、外部問題で崩れる

約1週間学習した時点で、ChatGPTが作成したテストでは正答率が9割を超えるようになっていました。

この時点では、自分自身もかなり仕上がっている感覚がありました。

しかし、問題を何度も解いているうちに、

「この問題、少し簡単すぎないか？」

と感じるようになりました。

そこで8月4日ごろ、AWS公式の模擬問題やUdemyなどで公開されている問題を解いてみました。

結果は、**正答率6〜7割程度**でした。

AWS公式の20問では、

**14/20、70%**

でした。

ChatGPTの中では9割以上取れていたにもかかわらず、外部の問題に変わっただけで一気に正答率が落ちました。

ここで初めて、

**「ChatGPTが出した問題に慣れているだけで、CLFの試験範囲そのものを十分に理解できていないのではないか」**

と疑うようになりました。

当初は8月8日に受験する予定でしたが、この状態では厳しいと判断し、試験日を8月11日に変更しました。

## 後半：AWS公式の試験範囲から学び直す

ここから学習方法を変更しました。

それまでは、

```text
ChatGPTにサービスを教えてもらう
↓
ChatGPTに問題を作ってもらう
↓
間違えたところを復習する
```

という進め方をしていました。

しかし、この方法ではChatGPTが一度も取り上げなかったサービスについては、未学習であることにすら気づけません。

そこで、AWS公式のCLF-C02の試験範囲やIn-Scope Servicesを基準に、

```text
AWS公式の試験範囲を確認
↓
サービス・概念を一覧化
↓
学習済み / 未学習を確認
↓
未学習項目をすべて学習
```

という方法に切り替えました。

ここから、主要サービスだけでなく細かなサービスや仕様も学習するようになりました。

## 試験直前：初見問題を意識して問題演習

試験前の最後の2日間は、問題演習を中心に行いました。

ただし、それまでとは問題の作り方を変えています。

ChatGPTに、

- 過去に出した問題をできるだけ使い回さない
- 似たAWSサービスを選択肢に入れる
- 単純なサービス名当てではなく、複数の要件から判断させる
- 未出・低頻度のサービスも出題する
- 細かな仕様を問う問題も入れる

といった条件を追加しました。

回答後には、

- なぜその選択肢が正しいのか
- 他の選択肢がなぜ間違いなのか
- 関連するAWSサービスとの違い
- AWS公式ドキュメント上の根拠

まで確認しました。

単純に正解を暗記するのではなく、選択肢を比較して「なぜその判断になるのか」を理解することを意識しました。

# ChatGPTだけで学習する際に感じた注意点

今回、CLF-C02の学習ではかなりの部分をChatGPTに任せました。

サービスの解説、理解度確認の小テスト、模擬試験、間違えた問題の解説まで、ほぼすべてChatGPTとの対話形式で進めています。

この方法自体は非常に便利でしたが、実際に学習を進める中で大きな問題にも気づきました。

一番注意した方がいいと感じたのは、

**「ChatGPTが合格できるレベルと判断したからといって、本当に試験範囲を網羅できているとは限らない」**

という点です。

## 原因1：そもそも未学習のサービスが残っていた

一番大きな問題はこれでした。

ChatGPTとの学習では、EC2、S3、RDS、Lambda、IAM、VPCなど、CLFで頻繁に登場する主要サービスはかなり学習できていました。

一方で、AWS公式のCLF-C02の試験範囲と照らし合わせると、一度も学習していないサービスや、名前だけしか知らないサービスがかなり残っていました。

後から追加で学習したものだけでも、例えば以下があります。

- AWS CloudHSM
- Amazon Cognito
- Amazon Detective
- AWS Directory Service
- AWS Firewall Manager
- AWS Resource Access Manager
- AWS CodeBuild
- AWS CodePipeline
- AWS X-Ray
- Amazon DocumentDB
- Amazon Neptune
- Amazon Kendra
- Amazon Lex
- Amazon Polly
- Amazon Textract
- Amazon Transcribe
- Amazon Translate
- Amazon AppStream 2.0
- Amazon WorkSpaces
- AWS Amplify
- AWS AppSync
- AWS IoT Core
- AWS License Manager
- AWS Compute Optimizer
- AWS Systems Managerの各機能
- AWS Storage Gatewayの各種類
- Amazon Lightsail
- AWS Elastic Beanstalk

さらにサービス以外にも、

- AWS CAF
- Federation
- IAM Policyの種類
- Permissions Boundary
- BYOL
- S3の各Storage Class
- AWS Organizationsの細かな仕様
- AWS Supportの機能差

など、細かな概念の抜けがありました。

つまり、

**ChatGPTが教えた範囲の中では高得点だったものの、そもそもChatGPTが教えていない範囲が存在していた**

という状態です。

これが最初の大きな反省点でした。

## 原因2：問題の出し方が単調だった

もう一つ大きかったのが、ChatGPTが作る問題の傾向です。

初期の問題では、

> S3上のデータをSQLで分析したい  
> → Amazon Athena

> DDoS攻撃を防ぎたい  
> → AWS Shield

のように、問題文の中に分かりやすいキーワードがあり、それに対応するサービスを選ぶだけの問題が多くありました。

これはサービスを最初に覚える段階では非常に役立ちます。

一方で、この形式を何度も繰り返すと、AWSを理解しているというより、

**「ChatGPTが作る問題のパターンを覚えている」**

状態になってしまいます。

特に選択肢にも問題がありました。

例えばAthenaを問う問題で、

```text
Athena
Cognito
Shield
SES
```

のように、明らかに用途の異なるサービスが並んでいれば、Athenaを詳しく理解していなくても正解できます。

実際の試験対策としては、

```text
Athena
Redshift
EMR
Glue
```

のように、すべて分析系サービスで一見正しそうな選択肢の中から、要件に最も合うものを選べる必要があります。

後半ではChatGPTへの指示を変更し、

```text
Athena
→ S3上のデータをSQLで分析

Redshift
→ データウェアハウス

EMR
→ Hadoop / Sparkによる大規模分散処理

Glue
→ ETL / Data Catalog
```

といった違いまで理解した上で回答する形式に変更しました。

## 原因3：同じ問題パターンが使い回されていた

学習後半でもう一つ気づいたことがあります。

一度学習したサービスについて、ほぼ同じ聞き方の問題が何度も出題されていました。

例えば、

```text
QuickSight
→ BI / Dashboard

Neptune
→ Graph Database

CloudFront
→ CDN / Cache
```

という内容を一度覚えたあとも、似た条件・似た選択肢の問題が何度も出題されます。

その結果、ChatGPTが作った65問の模擬試験では、

**63/65、96.9%**

という非常に高い正答率になりました。

しかしその後、

> これまでの問題を使い回さず、未出サービスや細かい仕様を含めた高難易度問題を出してほしい

と指示を変更しました。

すると正答率は、

**19/25、76%**

まで落ちました。

もちろん、問題自体の難易度が違うため単純比較はできません。

それでも、この差はかなり衝撃的でした。

> **ChatGPT内で96.9%取れていても、初見問題への対応力が96.9%あるとは限らない。**

サービスそのものを理解していた部分も当然ありますが、知らないうちに「問題文のパターン」を覚えていた部分もあったのだと思います。

## 原因4：最初に公式の試験範囲を棚卸ししていなかった

今回一番改善すべきだったと思う点です。

最初から、

```text
AWS公式のCLF-C02試験ガイドを確認
↓
出題範囲をすべて一覧化
↓
学習済み / 未学習を管理
↓
全範囲を一周
↓
問題演習
```

という順番にすべきでした。

実際には、

```text
ChatGPTにサービスを教えてもらう
↓
ChatGPTに問題を出してもらう
↓
間違えたところを復習
↓
またChatGPTに問題を出してもらう
```

という進め方をしていました。

この方法だと、ChatGPTが一度も取り上げなかったサービスは、その後の問題にも登場しない可能性があります。

つまり、

**未学習であることにすら気づけない**

という問題があります。

途中からAWS公式のIn-Scope Servicesと照合し、学習範囲を一つずつ確認する方法に変更しました。

ここから学習の精度がかなり上がりました。

## 原因5：細かい仕様を問う問題が不足していた

CLFはAWS資格の中では入門レベルですが、単純に「このサービスは何をするものか」だけでは解けない問題もあります。

後半では、例えば以下のような問題も追加しました。

```text
AWS Supportの特定機能を利用できる最低プランは？

Designated TAMを利用できる最低Support Planは？

SCPはIAM Userに権限を付与するのか？

OrganizationsがConsolidated Billingのみの場合、SCPを利用できるか？

Dedicated HostとCapacity Reservationの違いは？

Secrets ManagerとParameter Storeはどう使い分けるか？

Storage GatewayのFile / Volume / Tape Gatewayの違いは？
```

最初の学習では、このレベルの問題がほとんどありませんでした。

サービス名を知っていても、

**「どの条件なら、どのサービスを選ぶのか」**

まで理解していないと解けない問題があります。

試験対策としては、単純な名称問題だけでなく、こうした比較問題まで難易度を上げる必要があると感じました。

## 問題の下に公式情報を書かせるのも注意

途中から、

「必ず最新のAWS公式ドキュメントを確認して回答する」

というルールをChatGPTに追加しました。

この方針自体は非常に良かったのですが、別の問題が発生しました。

問題文の直後に、

> ○○というサービスでは、この機能を利用できます。

というようなAWS公式ドキュメントの説明まで表示されるようになったことです。

当然ですが、これでは問題を解く前に答えが分かってしまいます。

そのため最終的には、

```text
問題出題時
→ 問題文と選択肢だけ表示

回答後
→ AWS公式ドキュメントを確認して採点・解説
```

というルールに変更しました。

ChatGPTに資格問題を作らせる場合は、

**「公式情報は採点・解説時にのみ表示し、出題時にはヒントになる情報を表示しない」**

と明示的に指示した方が良いと思います。

# ChatGPTだけで学習する場合に一番怖いこと

今回一番感じたのは、ChatGPTが間違った情報を回答すること以上に、

**ChatGPTの中だけで学習・出題・採点を完結させてしまうこと**

の危険性です。

今回の初期状態は、

```text
ChatGPTが教える
↓
ChatGPTが問題を作る
↓
ChatGPTが採点する
↓
ChatGPTが「合格できるレベル」と判断する
```

という完全に閉じた学習ループになっていました。

ChatGPTが最初に学習範囲を漏らしてしまえば、その知識は問題にも出てきません。

また、同じChatGPTが問題を作るため、問題文や選択肢の傾向も似てきます。

その結果、

**ChatGPTが作ったカリキュラムに対する正答率は高いが、CLF-C02そのものへの対応力は十分ではない**

という状態が起こりました。

個人的には、これがChatGPTを資格学習に使う上で最も注意すべき点だと思います。

# 実際に受験してみて

結果として、CLF-C02には合格できました。

ただし、試験中に「余裕で合格できた」と感じていたわけではありません。

自信を持って回答できなかった問題もかなりありました。

特に印象に残っているのは、AWSサービス名そのものというより、

**「それ何だったっけ？」となるようなIT用語や、細かな条件を含む問題**

です。

また、責任共有モデルについては基本的な考え方は学習していましたが、

「このケースではAWSと利用者のどちらが担当するのか」

という具体的な判断まで、もう少し細かく学習しておけばよかったと感じました。

AWS Supportに関する問題でも、単純にSupport Planの名前を覚えるだけではなく、

**「この状況ではどのサポートや機能を利用するのか」**

という判断が必要になる問題があり、苦戦しました。

実際に受験したことで、

「主要サービスの名前と用途を覚えるだけでは不十分」

ということを改めて実感しました。

# 今ならChatGPTをこう使う

今回の経験を踏まえて、今からChatGPTを使ってAWS資格を勉強するなら、最初にAWS公式の試験範囲を基準にします。

まず、

```text
AWS公式試験ガイドを確認
↓
In-Scope Servicesをすべて一覧化
↓
各サービス・概念を簡単に一周
↓
未学習項目をなくす
```

というところから始めます。

その後、

```text
似たサービスを比較
↓
細かな仕様を理解
↓
本番形式の問題
↓
未出・高難易度問題
```

という順番で難易度を上げます。

そして最も重要なのが、

**ChatGPT製の問題だけで実力を判断しないこと**

です。

AWS公式の模擬問題や、Udemyなどの外部問題集も解きます。

ChatGPTで高得点を取れていても、別の出題者が作った問題で正解できなければ、まだ十分に理解できていない可能性があります。

個人的には、

```text
ChatGPT
→ 理解する・質問する・苦手分野を潰す

AWS公式 / 外部問題集
→ 本当に理解できているか確認する
```

という使い分けが良いと感じました。

# まとめ

14日間、学習の大部分をChatGPTに任せる形でCLF-C02を勉強し、最終的には合格することができました。

ChatGPTは、

- 分からないことをすぐに質問できる
- 自分の理解度に合わせて説明を変えてもらえる
- 問題を無限に作成できる
- 間違えた分野だけ重点的に復習できる

という点で、資格学習との相性はかなり良いと感じています。

一方で、今回の経験から、

**ChatGPTだけを信じて学習を完結させるのは危険**

とも感じました。

特に、

- 本当に公式の試験範囲を網羅できているか
- 同じ問題パターンを覚えているだけではないか
- 選択肢が簡単すぎないか
- 初見問題でも正解できるか

は、自分で意識して確認する必要があります。

今回の学習で一番大きな学びは、

> **「ChatGPTが合格できると言ったから大丈夫」ではなく、AWS公式の試験範囲と外部問題で必ず検証すること**

でした。

ChatGPTを先生として丸投げするのではなく、公式情報を基準にしながら、自分専用の家庭教師として使う。

現時点では、この使い方が資格学習において一番強いのではないかと思っています。
